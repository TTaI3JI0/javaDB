Лабораторная работа 2
Разработка упрощённой системы управления базами данных (СУБД) на Java

Создание структуры хранения данных, состоящей как минимум из двух таблиц, связанных по ключу. Предметная область произвольная.
Данные должны сериализироваться, храниться в файлах на диске и загружаться при запуске программы.
Поддерживаемые типы данных для таблиц: целое число, число с плавающей точкой, строка, дата, логическое значение (true/false)
Программа должна предоставлять консольный или графический (необязательное требование!) интерфейс, позволяющий выполнять следующий набор операций:
Вставка одной или нескольких записей в таблицу с проверкой уникальности первичного ключа
Обновление записей, удовлетворяющих условию.
Удаление записей, удовлетворяющих условию.
Вывод результата запроса на экран в табличном виде.
Обработка запросов. Парсинг SQL-подобного языка запросов простого формата (минимальное подмножество: INSERT INTO, SELECT, UPDATE, DELETE, на более высокую оценку CREATE TABLE, DROP TABLE). Гарантируется по условию, что все запросы будут простого формата:

INSERT INTO cars VALUES (1, 'Toyota', 25000.0, TRUE);
INSERT INTO cars (id, brand) VALUES (2, 'BMW');
SELECT * FROM cars;
SELECT brand, price FROM cars WHERE price > 20000;
UPDATE cars SET price = 30000 WHERE id = 2;
DELETE FROM cars WHERE brand = 'Toyota';

Для повышенной оценки реализовать  алгоритм индексирования. Индексы должны сохраняться на диск и восстанавливаться при запуске.
Поддержка CREATE INDEX idx_cars_brand ON cars (brand);
Оптимизация выполнения SELECT с использованием индексов (если условие по индексированному столбцу).

Нефункциональные требования
Язык программирования: Java (версия 8+);
Интерфейс: консольный или простой GUI
Надёжность: корректное восстановление после некорректного завершения (по возможности).
Код: соответствие принципам ООП, паттернам (например, DAO, Repository, Iterator), наличие Javadoc.
